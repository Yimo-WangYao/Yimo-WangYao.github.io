# Yimo Wang-Yao's Personal Website

Bilingual academic homepage for Yimo Wang-Yao, a statistics undergraduate at the Southern University of Science and Technology.

## Files

- `index.html`: Main page, including all English and Chinese content.
- `cv.html`: Print-friendly academic CV with reserved language and GRE score fields.
- `research/cba.html`: English research summary for the CBA player-influence project.
- `research/fig-*.svg`: Figures used in the research summary and homepage.
- `favicon.svg`: Browser tab icon.
- `suri.jpeg`: Profile photo used in the homepage.
- `IMG_3460.jpeg`, `IMG_3470.jpeg`: Additional image assets retained in the repository.

## Preview

Open `index.html` directly in a browser, or run a local static server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Updating Content

The homepage is intentionally kept as a single HTML file. Supporting CV and research-summary pages live in dedicated files. When adding an award, project, activity, or update, change both the English and Chinese versions in the same section.

Recommended details for a new achievement:

- Date
- Award or result name
- Issuing organization
- Link, if available
- One-sentence bilingual description

# 王姚以沫的个人主页

南方科技大学统计学本科生王姚以沫的双语学术主页。

## 文件

- `index.html`：主页面，包含全部中英文内容。
- `cv.html`：可打印的英文简历，预留语言成绩与 GRE 位置。
- `research/cba.html`：CBA 球员影响力项目的英文研究摘要。
- `research/fig-*.svg`：研究摘要与主页使用的图表。
- `favicon.svg`：浏览器标签页图标。
- `suri.jpeg`：主页头像。
- `IMG_3460.jpeg`、`IMG_3470.jpeg`：仓库中保留的其他图片素材。

## 本地预览

可以直接用浏览器打开 `index.html`，也可以在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 内容更新

主页主体保持为单个 HTML 文件，CV 与研究摘要使用独立页面。新增奖项、项目、活动或近期动态时，需要在同一栏目中同时更新中英文内容。

新增成果时建议提供：

- 日期
- 奖项或成果名称
- 颁发机构
- 相关链接（如有）
- 一句中英文简介
